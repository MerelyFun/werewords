# 界面参考与验证

[concept.png](concept.png) 使用内置 image_gen 工具生成，作为本项目的界面参考。网页使用原生 HTML/CSS/图标实现，不把图片中的文字或按钮当作界面。

## 生成提示规格

中文 Werewords 共用手机聚会助手，左右两个完整 390×844 手机屏幕：开局设置、先知夜晚看词。午夜深蓝 #101b27、暖白 #f4eddd、柔金 #cfaa69，中文衬线标题、清晰无衬线控件。月牙品牌；开局标题“今夜，谁在说谎？”，文案“一部手机，一桌朋友，一句隐藏的真言。”；实体身份卡与语音主持说明；人数、猜词时间、看词时间、词库、难度设置；语音试听条和开始按钮；每阶段可以跳过。夜晚页面包括夜晚/猜词/结算进度、先知睁眼提示、大字真言和计时、播报状态、暂停和跳过。简洁、留白、可实现，无营销区块、无手机外壳。

## 实现核对

- 深蓝背景、金色主按钮、暖白文字与原始参考一致。
- 月牙品牌和中文衬线标题保持同一层级。
- 开局设置使用单个分行容器，语音条与主按钮独立。
- 夜晚进度、提示、真言面板、语音条与底部控制顺序保持一致。
- 手机按单列排列，桌面居中保持适合一部手机操作的内容宽度。
- 有意变更：播报音频未就绪时显示真实状态，主按钮为“无声预览流程”；增加手动继续、结束确认，保留实体卡流程。
- 波形动画暂未加入：不以动画冒充正在播放真实音频。

已分别使用 view_image 检查概念图、浏览器开局图和夜晚图。浏览器验证使用 agent-browser 与 Playwright；内置浏览器本地地址被客户端阻止。390×844 的核心按钮可见，长内容可纵向滚动。
