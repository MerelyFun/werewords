# 本版规则与阶段

本版使用 Werewords 基础角色（村民、先知、狼人和带隐藏身份的镇长），用户在线下用实体卡分配。人数设置仅用于聚会配置，不进行数字发牌。更多角色暂不支持。

规则依据见 [RESEARCH.md](RESEARCH.md)。本网页是辅助工具，实体身份卡、指认、投票和回答标记的数量以线下所用版本为准。

## 阶段行为

| 阶段 | 页面与推进方式 | 跳过效果 |
| --- | --- | --- |
| 设置 | 人数、时长、词库与难度 | 使用当前设置开局 |
| 全体闭眼 | 播报后等待设置的夜晚时长 | 镇长选词 |
| 镇长选词 | 手动选中候选，记住后确认；没有超时 | 采用首个候选，进入镇长闭眼 |
| 镇长闭眼 | 隐藏词语、播报后等待 | 先知看词 |
| 先知看词 | 展示真言、播报后看词计时 | 先知闭眼 |
| 先知闭眼 | 隐藏词语、播报后等待 | 狼人看词 |
| 狼人看词 | 展示真言，狼人线下辨认同伴 | 狼人闭眼 |
| 狼人闭眼 | 隐藏词语、播报后等待 | 天亮提示 |
| 天亮 | 全体睁眼提示 | 猜词 |
| 猜词 | 默认 4 分钟，镇长确认猜中或标记耗尽 | 视为未猜中，进入讨论 |
| 狼人指认 | 猜中词后，默认 15 秒 | 人工确认指认结果 |
| 讨论投票 | 未猜中或标记耗尽后，默认 60 秒 | 人工确认投票结果 |
| 人工确认 | 根据实体卡选择是否找到目标 | 不判定胜负，结束本局 |
| 结果 | 展示阵营结果与真言 | 返回设置 |

所有定时阶段可暂停或跳过。播报音频不可用时，夜晚暂停自动推进，页面清楚标为无声预览；白天及讨论计时可预览。

## 胜负输入

| 猜词结果 | 现场确认 | 网页结果 |
| --- | --- | --- |
| 猜中 | 狼人指认先知成功 | 狼人胜 |
| 猜中 | 狼人未找到先知 | 村民胜 |
| 未猜中 | 投票找到狼人 | 村民胜 |
| 未猜中 | 投票没找到狼人 | 狼人胜 |
| 任一 | 跳过人工确认 | 未判定 |

镇长保留实体卡上的阵营：狼人镇长可误导回答，先知镇长可以被指认。网页不需要保存他的身份，所有角色按对应夜晚提示行动。

多狼人指认与平票由玩家结合规则在线下处理，网页提供简短判定提示，不计算或存储每个人的投票。回答按钮是展示工具，不代替实体标记库存；耗尽时手动点击对应按钮。

## 时间与信息边界

- 播报结束后开始行动倒计时，不把播报时间占用为看词时间。
- 夜晚切后台即暂停，暂停、玩法弹窗和重开弹窗都遮挡看词画面。恢复后重播阶段提示。
- 白天根据截止时间校正，切后台不重置倒计时。
- 只本地保存配置，不保存当局真言；刷新回设置。重开清空秘密与候选。
- 语音不读出真言本身。当前使用用户提供的录音剪辑，需完成真实播放及手机试听验证后，才能声称全员闭眼的正式流程可用。
