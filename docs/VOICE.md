## 重新裁剪与检查

准备 Python，并确保 ffmpeg 和 ffprobe 位于 PATH。在项目目录运行：

```sh
npm run voice:cut
npm run voice:check
```

裁剪脚本读取原件和切点，核对源文件哈希，按音频样本裁剪、重置时间戳，再加短淡入淡出并编码 MP3。检查命令核验片段及清单，不依赖 OpenAI 生成元数据或网络凭据。调整切点后应重新裁剪、检查并试听，确认句首句尾完整、音量合适、阶段对应正确。

本轮 `voice:check` 全部 13 段通过；构建、25 项单元测试和 13 项浏览器测试通过，其中真实录音测试使用原生 WebAudio 验证全部片段可解码、有有效信号，试听自然结束，跳过阶段会停止旧音源。自动识别用于辅助核对切点，不等同于人工试听；手机扬声器及 iOS/Android 自动播放仍需实机验证。

## 播放约定

- 开局先点击试听，确认所有人能听清声音，再闭眼。
- 每段播放结束后再开始对应行动时间，避免未听完便收回词语。
- 切换、跳过、重开时中止当前声音，清理旧回调，避免不同角色提示重叠。
- 镇长选词需要人工确认，其余夜晚阶段按行动时间自动推进。
- 音频不可用时明确提供手动无声预览；播放失败时暂停并显示恢复操作。
- 指认默认十五秒，讨论默认六十秒；录音若提及具体时长，应与游戏设置一致。
- GitHub Pages 播放静态资源，路径基于 Vite 的 `BASE_URL`，兼容仓库子路径。

## 可选模型生成工具

[generate-voice.mjs](../scripts/generate-voice.mjs) 保留为将来另行生成语音的工具，当前无需执行。只有主动选择重新生成时，才在本机配置 `OPENAI_API_KEY` 并运行 `npm run voice:generate`；这会请求 OpenAI 语音接口，并替换对应静态录音与来源记录。

密钥不能进入客户端或 Git；网页及发布产物始终不需要密钥。使用可选模型生成后，应重新检查并试听，并如实标明 AI 合成来源。
