## 选词和分级原则

- 优先完整、可用“是／否／可能”逐步逼近的对象、行为、人物类型和状态。标准侧重可见事物与常见平台行为；挑战侧重比喻、抽象状态、跨圈传播的梗义。
- 以一般年轻聚会玩家的共同知识为参考；不使用极小圈暗号、长篇台词补全、纯拼音缩写串或低俗攻击词。保留少量通行混写“嗑CP”，因为目标是完整行为概念。
- 保留难以直猜但可拆解的趣味比喻，如电子榨菜、雪糕刺客、社交电量、电子木鱼；避免水豚与卡皮巴拉等同一对象别名在本部分重复计数。
- 不附带来源文章原解释。词面、分组和难度为本项目自编选择；来源仅支撑年份背景与使用语境，不意味着来源作者背书本游戏或难度。
- 没有声称覆盖全部平台和年度热门词。是否过难仍需真人试玩；镇长候选选词可以照顾当前玩家的熟悉程度。
