# 万象趣猜：自编综合词库

2026-09-09 完成本地接入。660 词，标准 430、挑战 230，14 个编辑分类。首页仅显示词库名，支持独立选择或与其他库混抽，不改变现有默认选库。

## 选词原则

围绕狼人真言的封闭式问答，优先选择能通过“人／物／地方／行为／概念→现实或虚构→用途／特征”逐步缩小范围的答案。标准强调常识和具体形象；挑战强调抽象含义、反差与跨类别联想，难度是项目编者判断，不是官方分级。

- 人物涵盖历史、神话、动漫、影视、文体人物；景物涵盖中国与海外地标和自然现象。
- 网络部分参考2021–2025年度热词与跨平台常用表达，补充经典梗。不是所有平台热榜全集，也不声称2026最新；年份与使用语境见 [网络词依据](GENERATED_INTERNET_SOURCES.md)。
- 趣味题例如不倒翁、黑匣子、导盲犬、电子榨菜、雪糕刺客、回声、时间旅行、沉没成本。难题仍以熟悉概念为主，不依靠生僻专名或整段台词。
- 编者进行了词面去重和别称审阅：不把孙悟空／齐天大圣、水豚／卡皮巴拉分别凑数；搭子／饭搭子等相近题也进行了替换。相关但不同的概念仍保留。
- “天花板、谷子、锦鲤”等允许常用本义或网络义，镇长选定后应保持当局解释一致；是否猜中由现场人工判断，不要求逐字复述。

## 数据与维护

运行数据：[generated-words.json](../src/data/generated-words.json)。候选原稿为 generated-everyday-groups.json、generated-culture.json、generated-internet.json、generated-extra-groups.json；最终人工替换记录在 [构建脚本](../scripts/build-generated-words.mjs)，原稿不直接用于抽词。

重建命令：`node scripts/build-generated-words.mjs`。脚本对重复词与未知难度直接报错，输出稳定顺序的ID；后续扩展应在原稿末尾追加，避免改动旧ID。

库ID：`generated-wanxiang`。普通词语与专名由项目自主选编，没有复制外部游戏题库或文章解释；名称不表示相关人物、品牌或平台背书。跨库同名沿用现有混抽去重。
